# Onlang iOS SDK 1.0.0-rc.1

Add `https://github.com/onlang-ai/onlang-ios.git` in Xcode (File → Add Package Dependencies) or in `Package.swift`:

```swift
.package(url: "https://github.com/onlang-ai/onlang-ios.git", from: "1.0.0-rc.1")
```

Then depend on `OnlangKit` (and `OnlangStoreKit` for StoreKit 2). Guide: https://onlang.io/docs/sdk/ios

This repository is generated from the Onlang monorepo on every SDK release.
